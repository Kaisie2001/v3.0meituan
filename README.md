## meituan-gomap-agent-demo

### 本地运行

1. 安装 Node.js 18+（建议 22 LTS）
2. 安装依赖

```bash
npm install
```

3. 启动开发服务器

```bash
npm run dev
```

4. 浏览器打开

```text
http://localhost:3000
```

### 使用方式（Demo）

1. 在“自然语言目标”里随便输入一句话（例如：想在下午出去玩几小时、别太远、预算多少、几个人等）
2. 点击“生成成行地图”
3. 如果关键条件缺失，会弹出补全弹窗（出发时间/时长/人数/通勤分钟），按提示点选后确认
4. 接着会弹出“路线偏好问答 Agent”（出行方式 → 优化目标；选择“其他”可语音/文本输入）
5. 地图会显示 OpenStreetMap 底图 + 规划的折线路径（尽量闭环），点击 POI 才会在下方显示详情
6. 在 POI 详情里点击“我不喜欢”，会避开该点并重新规划
7. 点击“确认并执行”，会模拟订位/下单/发送并展示可转发文案与凭证结果（不展示详细 trace）

### 说明

- 本项目基于 Next.js 15，Node.js 版本过低会在 `next build` / `tsc` 阶段出现语法报错（例如 `Unexpected token '?'`）。
- 地图底图使用 OpenStreetMap 公共瓦片服务；如果你的网络环境无法访问，会看到“底图加载失败”的提示（组件会自动尝试切换多个公开镜像）。
